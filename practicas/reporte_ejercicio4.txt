RESPUESTAS A LAS PREGUNTAS
============================================================

¿Hay algún valor de x donde el error sea sorprendentemente alto?

Sí. El error relativo se dispara cuando el valor real está muy cerca
de cero, porque la fórmula divide entre el valor exacto:

    error_relativo = |aprox - exacto| / |exacto|

Si 'exacto' es casi cero, el denominador se hace minúsculo y el
cociente se infla aunque el error absoluto sea chiquito.

Ejemplos típicos:
  - coseno(x) cerca de x = pi/2 ≈ 1.5708, donde cos(x) ≈ 0.
  - seno(x) cerca de x = pi ≈ 3.1416, donde sen(x) ≈ 0.
  - ln(x) cerca de x = 1, donde ln(1) = 0 exactamente.

En esos puntos el error relativo puede dar valores grandes o incluso
divergir, aunque el error absoluto sea del orden de 1e-16.

Por eso el profe evitó a propósito valores como pi/2 en las pruebas
de coseno: no porque la función esté mal, sino porque el error
relativo no es una buena métrica cerca de los ceros de la función.
